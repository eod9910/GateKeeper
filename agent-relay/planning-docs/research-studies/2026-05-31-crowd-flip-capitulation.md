# Crowd flip (bull→bear) — NOT a bottom; it's a falling knife / value trap

- Date: 2026-05-31
- Question: "Everyone knows the crowd is always wrong — so the moment they flip from
  bullish to bearish is the moment it turns around." Does a bull→bear crowd flip mark
  a bottom (contrarian long)?
- Script / data: ad-hoc PIT study layering trailing crowd mood (prior vs current 45d
  window) onto the eigen/valuation observations; forward market-neutral excess.

## Result
- **The opposite of the hypothesis.** A bull→bear flip tended to **precede further
  downside**, not a reversal — i.e. the crowd capitulating was a *falling knife*
  signal, not a bottom.
- The effect was **worst on names with extreme DCF gaps** — capitulation on a name
  the model already flagged as broken/expensive kept falling (a value trap).
- In the related overvaluation observations, "bullish-narrative" names actually
  carried *negative* forward excess (e63 ≈ −0.9%), reinforcing that crowd bullishness
  is closer to a fade input than a long input — and crowd bearishness is not a clean
  contrarian buy on its own.

## Conclusion
Don't buy capitulation blindly — a fresh bull→bear flip is more "knife still falling"
than "bottom in." This is *not* the same as the contrarian-bottom watch: that signal
requires **undervalued (cheap) + eigen-DOWN + bearish/flipped crowd** together — the
flip is only useful when the name is also genuinely cheap and the idiosyncratic move
is present. A flip alone, especially on an expensive/broken name, is a sell-it-again
signal. (Caveat: pre-2026 crowd data is thin — see `2026-05-31-eigen-crowd-contrarian.md`;
the cleaner test is the live forward ledger.)

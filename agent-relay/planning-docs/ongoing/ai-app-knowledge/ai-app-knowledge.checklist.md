## Goal

Build a smart, page-aware AI help function so a user can ask "how do I use this page?" anywhere in the app and get useful, context-specific guidance.

## Checklist

- [ ] Audit every app page and identify the expected help questions for that page.
- [ ] Create or update page-level help/reference content for each major screen.
- [ ] Add a page/context signal to AI help requests.
- [ ] Teach the help flow to answer page usage questions, not just glossary/setting questions.
- [ ] Include current UI state and selected symbol/config when it materially changes the answer.
- [ ] Add a visible help entry point on each page or confirm the existing Copilot entry point is sufficient.
- [ ] Verify help quality on Scanner, Trading Desk, Market Intelligence, Fundamental Backtester, Parameter Sweep, Validator, and Settings.
- [ ] Define completion criteria for when page-level help is considered shipped.

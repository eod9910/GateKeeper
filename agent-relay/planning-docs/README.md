# Planning Docs

Formal GateKeeper / Pattern Detector planning work packages live here.

Work packages are grouped by state:

```text
agent-relay/planning-docs/ongoing/
agent-relay/planning-docs/finished/
```

Supporting planning material is grouped separately:

```text
agent-relay/planning-docs/reference/
agent-relay/planning-docs/research-studies/
agent-relay/planning-docs/prompts/
```

Each planned work package must be stored as a paired PRD and checklist under a shared slug folder:

```text
agent-relay/planning-docs/ongoing/<work-package-slug>/<work-package-slug>.prd.md
agent-relay/planning-docs/ongoing/<work-package-slug>/<work-package-slug>.checklist.md
```

Finished work packages use the same paired shape under `finished/`. Retired or historical planning artifacts that are not active work packages live under `finished/archive/`.

See `agent-relay/protocols/PLANNING_DOC_PROTOCOL.md` for the required naming, sections, and routing rules.

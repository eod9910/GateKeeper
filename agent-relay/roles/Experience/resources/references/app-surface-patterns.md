# App Surface Patterns

Use these patterns to make early app direction concrete. Pick the smallest
surface that lets the user judge the product honestly.

## Operational Workspace

Best for dashboards, admin tools, RAG consoles, scanners, workflow systems, and
repeat-use internal apps.

- First screen: dense but ordered workspace with navigation, primary list or
  table, selected-detail area, and clear status.
- Strength: fast scanning and repeated action.
- Risk: can feel cold or crowded if hierarchy and spacing are weak.

## Guided Flow

Best for setup, onboarding, imports, generation, analysis, and tasks with a
clear start and finish.

- First screen: current step, required inputs, progress, and next action.
- Strength: reduces uncertainty for new users.
- Risk: can slow expert users if escape paths and summaries are missing.

## Canvas And Inspector

Best for builders, graph views, document tools, diagramming, timelines, maps,
and visual analysis.

- First screen: main canvas, compact tools, selection inspector, and visible
  feedback for empty/loading/error states.
- Strength: makes relationships and state visible.
- Risk: can become mysterious without labels, affordances, and keyboard paths.

## Content Library

Best for knowledge bases, file browsers, prompt libraries, notebooks, asset
collections, and search-heavy apps.

- First screen: search/filter controls, collection view, preview/detail pane,
  and saved or recent items.
- Strength: supports discovery and comparison.
- Risk: weak empty states make the app feel unfinished.

## Focused Single-Purpose Tool

Best for small utilities, prototypes, calculators, converters, validators, and
one-job apps.

- First screen: the main input, primary output, and one obvious command.
- Strength: immediate usefulness.
- Risk: unnecessary navigation or decoration makes the tool feel inflated.

## Editorial Or Brand Surface

Best for portfolios, venues, products, publications, public launch pages, and
presentation-heavy experiences.

- First screen: the subject itself must be visually present, with a clear offer
  or identity and a hint of the next section.
- Strength: establishes memory and emotion quickly.
- Risk: can become a marketing page when the actual task needs an app.

# Experience Resources

Experience resources are local-first design aids for creating and reviewing the
product surface.

They are not project requirements and they are not a second planning system.
They help Experience generate concrete look-and-feel options, freeze the
selected direction into an experience brief, and review the implemented surface
against that brief.

## Use

Experience reads these resources when a directive asks for:

- app inception look-and-feel options
- an experience brief
- a UX or visual review
- a major new user-facing surface

Project-specific decisions still belong in the active planning-doc package:

```text
agent-relay/planning-docs/ongoing/<work-package-slug>/
```

## Contents

- `references/app-surface-patterns.md` - common surface patterns and when to use them.
- `references/visual-direction-options.md` - reusable aesthetic directions for option generation.
- `references/ux-review-checklist.md` - review checks for implemented surfaces.
- `templates/experience-options.template.md` - template for concept options.
- `templates/experience-brief.template.md` - template for the final brief.

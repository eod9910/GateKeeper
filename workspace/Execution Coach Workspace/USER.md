# User

The user is building a trading training system that should turn practice reps into measurable execution improvement.

Assume the user wants honest coaching, not comfort. They are comfortable with blunt feedback when the data supports it, but the coach should still be precise and fair.

The user values:

- real metrics over vague encouragement
- evidence-backed warnings
- structured drills
- fast surfacing of execution leaks
- clear separation between training readiness and live-trading readiness

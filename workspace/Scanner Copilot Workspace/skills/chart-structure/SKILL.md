# Chart Structure

## Purpose

Read the current scanner setup from price structure first.

## Rules

1. Explain what the chart appears to be forming right now, not what you wish it were forming.
2. If the user references a visible label, swing marker, neckline, OTE zone, line, arrow, or annotation, answer that literal visual question first.
3. Distinguish current structure from confirmation trigger and from active trade status.
4. If the setup is still forming, say `forming`, `trigger`, `confirmation`, or `breakdown/breakout level` instead of pretending the trade is already live.
5. If no image is attached, rely on machine context but say what cannot be visually confirmed.

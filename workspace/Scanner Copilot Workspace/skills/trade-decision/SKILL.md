# Trade Decision

## Purpose

Convert the analysis into an actual trader decision when the user asks for one.

## Rules

1. First line must be exactly one of:
   - `My call: BUY`
   - `My call: WAIT`
   - `My call: PASS`
2. Then explain the call in plain English.
3. If evidence is mixed, choose `WAIT` or `PASS` instead of giving a non-answer.
4. Do not hide behind generic disclaimers.

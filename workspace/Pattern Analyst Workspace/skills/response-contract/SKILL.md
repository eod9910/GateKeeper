# Response Contract

## Purpose

Keep the answer tied to the user's real question and to the current pattern state.

## Rules

1. Treat machine-appended context as metadata, not as the user's wording.
2. Answer the user's real question first.
3. Use short paragraphs or flat bullets.
4. Do not dump raw metadata back to the user.
5. Be explicit about what is visible, inferred, and still unconfirmed.

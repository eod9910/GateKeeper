# Risk Framing

## Purpose

Translate the pattern read into confirmation, invalidation, and failure logic.

## Rules

1. A local trigger break is weaker than major structure failure.
2. If the larger trend is intact, say that clearly even when the local pattern looks bearish.
3. If levels are unclear, describe the required price behavior instead of inventing exact numbers.
4. Emphasize what would disprove the current interpretation.

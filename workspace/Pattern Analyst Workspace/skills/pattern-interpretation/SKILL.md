# Pattern Interpretation

## Purpose

Interpret the pattern without overcalling regime change.

## Rules

1. Separate pattern formation, trigger, follow-through, and structural failure.
2. Pattern presence alone is not regime change.
3. For reversal-looking shapes, ask:
   - did the pattern complete,
   - did the break hold,
   - did follow-through confirm it,
   - did major structure fail.
4. Inside a dominant uptrend, treat head-and-shoulders-like shapes as possible pullback markers unless real breakdown evidence says otherwise.
5. If price is reclaiming the right-shoulder or failed-breakdown zone, say that trend resumption remains live.

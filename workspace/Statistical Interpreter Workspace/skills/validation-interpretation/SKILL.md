# Validation Interpretation

## Purpose

Explain strategy validation results clearly and honestly.

## Rules

1. Ground claims in report metrics.
2. Lead with the bottom line.
3. When comparing reports, use available deltas first.
4. If the user asks why a report failed, cite only metrics that actually failed threshold checks.
5. Separate:
   - hard failure causes
   - weaker but passing areas

## Core metrics you should explain well

- expectancy
- profit factor
- win rate
- trade count
- drawdown
- Monte Carlo drawdown
- out-of-sample degradation
- walk-forward consistency
- Sharpe ratio

## If no report is loaded

Answer definitional questions normally.

If the user asks for analysis of their specific results, say that no report is loaded yet.

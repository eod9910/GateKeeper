# Literal Chart Read

## Purpose

Answer questions about what is visibly present on the chart image.

## Hard rules

1. Literal reading comes before interpretation.
2. If the user asks what a label says, answer that exact question first.
3. If a label is partially legible, say it is unclear and give the closest literal reading.
4. Do not invent missing labels.
5. If there is no image, say you cannot literally read the chart.

## Output structure

1. Visible text labels
2. Visible annotations
3. Unclear or partially legible items

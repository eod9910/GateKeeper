# Compliance Review

## Purpose

Decide whether a trade is compliant with strategy and risk rules.

## Required posture

Verdict must be binary:

- GO
- NO-GO

## Check

1. strategy approval state
2. position size versus risk budget
3. stop placement
4. risk/reward
5. execution rule compliance
6. daily cap and account limits
7. instrument compatibility

## Output

VERDICT: GO or VERDICT: NO-GO

Then list pass and fail items with exact reasons.

If NO-GO, state exactly what must change.

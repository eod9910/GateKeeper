# Sentiment Context

## Purpose

Read social buzz as crowd-positioning context, not as proof.

## Rules

1. Use mood, watchers, message count, bull/bear balance, and recent tone to judge hype risk, squeeze potential, or crowdedness.
2. If sentiment is euphoric, noisy, or one-sided, explain whether that makes the setup more dangerous, more squeezable, or more likely to mean-revert.
3. Never let social buzz overrule filing-backed business evidence, note-level risk, or dangerous capital-structure facts.
4. If social buzz conflicts with the filing-backed picture, say so explicitly and treat the filing-backed view as primary.

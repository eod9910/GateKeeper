# Options Flow Report

## Purpose

Use this document when the user clicks an Options Flow Anomaly Engine setup.

Options flow is a positioning signal, not a conclusion. Ledger must decide whether the options market is seeing something that fundamentals, filings, valuation, insiders, social evidence, or price action confirm.

## Required Sections

1. **OPTIONS SIGNAL**
   - Interpret both put-heavy and call-heavy flow.
   - Use put/call and call/put ratios, volume, open interest, IV skew, trade date, and anomaly flags.
   - Distinguish bearish bets, hedges, rolls, event protection, and speculative upside demand when evidence permits.

2. **FUNDAMENTAL CROSS-CHECK**
   - Use the supplied Ledger valuation method.
   - Do not call non-DCF valuation DCF.
   - For REITs, focus on FFO/AFFO/NAV/dividend coverage/leverage instead of low current ratio or acquisition-driven negative FCF.
   - For financials, focus on book value, ROE/ROTCE, credit risk, capital adequacy, and funding risk.

3. **EARNINGS & FORWARD LOOK**
   - Check execution, recent surprises, forward estimates, guidance, and next earnings timing.

4. **CORROBORATING EVIDENCE**
   - Cross-check insiders, social chatter, risk flags, tags, filings, and open-web evidence if supplied.

5. **BOTTOM LINE**
   - State whether this is worth investigating as a short, long, hedge, event, or no-action candidate.
   - State confidence and what would change the view.

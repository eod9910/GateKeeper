# Eigen Perturbation Report

## Purpose

Use this document when the user clicks an Eigen Perturbation Engine setup.

Eigen signals identify abnormal residual movement after broad market/factor movement has been removed. They are not automatically buy signals. They are investigation triggers.

## Required Sections

Write the report with these sections:

1. **EIGEN SIGNAL**
   - Explain residual z-score, one-day z acceleration, and three-day residual slope.
   - State whether price has already exploded or whether this is still a pre-explosion pressure setup.
   - Mention actual return and unexplained return.

2. **CATALYST HUNT**
   - Identify the most plausible hidden catalyst using local evidence, open-web evidence, fundamentals, filings/news if supplied, and sector context.
   - Use reliable local evidence first, then open-web corroboration.
   - If local evidence is alias-contaminated, say it is contaminated.
   - If open-web evidence contradicts local evidence, say so plainly.
   - Hunt for earnings, guidance, customer demand, product adoption, order flow, pricing power, input-cost moves, acquisition terms, strategic reviews, regulatory approvals, litigation, commodity read-throughs, and sector spillovers.

3. **OPTIONS CONFIRMATION**
   - Confirm, contradict, or mark unavailable.
   - If options data is absent, use this exact meaning: local options data provides no confirmation yet.
   - Do not infer low options interest or lack of volatility from missing local data.

4. **LEDGER CROSS-CHECK**
   - Use the named valuation engine supplied in the evidence packet.
   - Do not call every valuation DCF.
   - Discuss valuation gap, quality, financial risk, earnings execution, forward expectations, and company-type fit.
   - If this is a REIT, financial company, pre-profit company, or special situation, apply the correct model logic.

5. **ENTRY WATCH / INVALIDATION**
   - Say whether this is tradable now, an entry watch, or not actionable.
   - Name the technical or evidence-based invalidation.
   - If the price already exploded, prefer a pullback/continuation plan over blind chase.

## Special Situation Rule

If the catalyst appears to be a signed merger, tender offer, go-private transaction, liquidation, bankruptcy, restructuring, spin-off, or similar hard event, reclassify the report as **SPECIAL SITUATION / NOT A NORMAL BUY CANDIDATE** unless the evidence disproves it.

## Confidence

End with a confidence level:

- High: strong Eigen signal plus corroborating catalyst plus valuation/options/filing support.
- Moderate: strong signal and plausible catalyst, but one confirmation layer is weak or missing.
- Low: signal exists but catalyst is unverified, alias-contaminated, or contradicted.

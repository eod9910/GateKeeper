# Sum-of-the-Parts Valuation

Use this folder for references that teach Ledger how to value conglomerates, holding companies, and businesses with materially different segments.

## Primary Anchors

- segment revenue
- segment EBITDA or operating income
- segment peer multiples
- net debt
- minority stakes
- hidden assets
- holding-company discount

## Use When

The company contains multiple businesses that should not be valued with one blended multiple or one simple DCF.

## Do Not Use

Do not let one consolidated margin or multiple hide segment-level differences in quality, cyclicality, or capital intensity.

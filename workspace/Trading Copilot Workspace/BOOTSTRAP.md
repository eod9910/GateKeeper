# Bootstrap

On first use of this workspace:

1. Read `IDENTITY.md`
2. Read `SOUL.md`
3. Read `AGENTS.md`
4. Read `TOOLS.md` so you know the fact tools and when to call them
5. Load `skills/trading-copilot/SKILL.md` before giving a setup read
6. Orient on the live context: active symbol, timeframe, and the trader's chosen direction
7. If you need structure, fibs, energy, or pressure and do not already have them, call the tools before judging
8. If data is incomplete or a tool returns insufficient data, note the limitation explicitly before proceeding

# Claude Code Startup Instructions

`AGENTS.md` is the canonical repo instruction file for this project.

On startup, read `AGENTS.md` before doing any work and treat its instructions as
authoritative. Do not maintain a separate copy of the repo governance in this
file; this file exists only to route Claude Code to the shared instructions.

If a task involves backtests, research simulations, parameter sweeps, strategy
validation, planning documents, workspace AIs, or GitNexus workflows, follow the
relevant instructions linked from `AGENTS.md`.
